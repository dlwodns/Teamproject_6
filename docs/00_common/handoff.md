## 위험

1. **사내 메일 연동 불가**: 더미 메일 성능이 실제 성능을 보장하지 않는다. 더미를 사내 형식에 가깝게 유지하고, 기업 적용은 연동 방법 제안까지로 한다.
2. **범위 확대**: 대시보드 · 에이전트 · 음성이 한꺼번에 들어왔다. 업무 추출 → 대시보드 → 완료 처리를 먼저 끝내고 나머지를 붙인다.
3. **엑사원 속도**: CPU에서 메일 1통 약 25초. 라우터로 엑사원 호출을 줄이고 백그라운드로 처리한다. ai가 멈춰도 대기 메일을 화면에 보여 준다.
4. **자동 완료 오판**: 답장 후 확인 팝업(D23)과 되돌리기로 막는다. 팝업이 너무 잦으면 부담이 된다.
