# 에이전트 시나리오 평가 (시연 장면 기준)

> 담당: 기획(이재운) · 정의 2026-11-15 · 측정은 첫 배포 뒤 시연 DB로(11/20 전)
> IR 노션 흐름 6 · 흐름 3 시연 장면과 같은 내용이다. 한쪽을 바꾸면 다른 쪽도 고친다.

## 원칙

- **main에 들어간 기능만** 쓴다. 준비 안 된 행동(T01 오늘 요약 · T06 · T07 회신/재촉 초안 · T10)과 AI 다듬기(#95)는 준비되면 시나리오를 추가한다.
- 같은 시연 DB · 같은 시연 시각(아침 9시)으로 **시나리오마다 3번** 돌린다. 결과는 `성공 / 3`으로 적는다.
- 성공 기준을 **모두** 만족해야 성공이다. 하나라도 어긋나면 실패로 적고, 무엇이 어긋났는지 한 줄 남긴다.
- 결과는 잰 숫자 그대로 쓴다("3번 중 3번"). '항상' · '100%' 같은 말로 바꾸지 않는다.

## 준비

```bash
cd backend
python -m app.dev.seed reset --db demo.db --yes
python -m app.dev.seed load  --db demo.db --as-of <시연 기준 시각> --source ../data/dummy/demo_mails.json
python -m app.dev.seed check --db demo.db
```

- `--source`를 빼면 `dummy_mails.json`(보낸 메일 없음)으로 채워져 S3을 할 수 없다.
- 데이터 범위: 2026-10-13 10:20부터 2026-10-19 17:45까지(받은 100통 + 보낸 15통).
- 회차마다 `reset → load`로 처음 상태에서 시작한다.

## 시나리오

| # | 흐름 | 성공 기준 |
|---|---|---|
| S1 아침 기한 지난 일 처리 | 브리핑(아침) → '기한 지남' 항목 → [완료] → [실행 취소] | 브리핑에 보임 · 이유와 근거 문장 보임 · 대시보드 건수 1 줄어듦 · 취소하면 원래대로 |
| S2 말로 미루기 + 확인 + 되돌리기 | "한빛은행 견적 건 금요일로 미뤄"(T05) → 확인 카드 → 실행 → "방금 거 취소해"(T04) | 대상이 맞음 · 2건 이상이면 확인 카드 · '나중에(금요일)'로 바뀜 · 취소하면 원래대로 |
| S3 답 없는 요청 챙기기 | '답 기다림 › 답 없음' 항목 → 이유('며칠째') → [메일 열기] → [그만 기다리기] | 내가 보낸 요청이 뜸 · 며칠째인지 맞음 · 원래 메일이 열림 · 그만 기다리면 목록에서 빠짐 |
| S3′ 애매한 명령 되묻기 (시연 DB가 없을 때) | "빼 줘" · "초안 쓰고 회의 잡아 줘" | 실행하지 않고 되묻는다 |

**S2 주의:** 시연 데이터에 제목에 '견적'이 들어간 메일이 5통 있다. "견적 건 금요일로 미뤄"만 말하면 대상이 여러 개라 확인 카드가 뜬다. 무대에서는 대상을 좁힌 문장을 쓰고, 확인 카드를 보여 주고 싶을 때만 넓은 문장을 쓴다.
