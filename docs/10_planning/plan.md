## 6. 완료 기준 (입력 → 기대 결과)

- 각 파트가 `plan.md` 작업 목록을 PRD v3 기능과 1:1로 연결할 수 있다.
- 구조도 v3에 화면 3개(대시보드 · 메일 · 설정)와 에이전트 패널의 API가 모두 있다.

## 7. 위험

- 범위 확대: 대시보드 · 에이전트 · 음성이 한꺼번에 들어온다. 핵심(업무 추출 → 대시보드 → 완료 처리)을 먼저 끝내고 나머지를 붙인다.
- PRD와 실제 구현이 어긋난다. PRD는 '현재 정답만 남긴다' 규칙을 유지한다.
