## 1. 엑사원이 맡는 역할

실서비스 AI는 엑사원(EXAONE 3.5 7.8B)만 쓴다. 엑사원은 판단이 필요한 좁은 일만 하고, 계산 · 실행은 코드가 한다.

| 기능 | 엑사원이 하는 일 | 코드가 하는 일 | 근거 |
|---|---|---|---|
| 메일 분석 (`POST /classify`) | 규칙으로 판단하지 못한 메일만 받아 분류(회신 · 요청 · 검토 · 공지 · 기타) · 할 일 문장 · 기한 표현 · 본인 지목 여부를 JSON으로 낸다 | `ai/`: 규칙 판별 · 라우터, 날짜 환산(받은 날짜 기준, 시간 없으면 18:00), 우선순위, JSON 형식 검사 | D14 · D39 · AI-T2 |
| 명령 해석 (`POST /agent/plan`) | 규칙으로 행동이 하나로 정해지지 않은 지시만 받아 `{action, target, params, source}`를 낸다. 행동은 레지스트리 목록(T01~T14) 안에서만 고른다 | 규칙 매칭 · 허용 목록 검증(`ai/`), 대상 해석 · 확인 정책 판정 · 실행 · `action_log` 기록(`backend/`) | D37 · D44 · `detail.md` 4절 |
| 요약 · 초안 (`POST /summarize` · `/draft`) | 오늘 요약, 영문 메일 한국어 요약, 회신 초안 · 초안 작성. 보여 주기만 하고 보내지 않는다 | 입력 개인정보 가리기(`backend/privacy/`), 길이 검사 | D42 |
| 음성 (`POST /stt`) | 하지 않는다. 음성은 글자로 바뀐 뒤 명령 해석과 같은 길을 탄다 | 음성인식(브라우저 · 서버 Whisper 교체형) | D29 |
| 다음 단계 | 외국어 메일 번역 전문, 회신 필요 여부 판별(무응답 대상 좁히기, P2) | — | D12 · D43 |

- 엑사원에 맡기지 않는 것: 날짜 계산, 우선순위, 확인이 필요한지 판정, 처리 상태 변경, 기능 실행, 메일 발송 · 삭제. 답장 후 완료도 엑사원이 판정하지 않는다 — 답장을 보내면 백엔드가 같은 메일의 미완료 업무를 "완료할까요?" 팝업으로 묻고 사용자가 정한다(D48, D36 대체).
- 메일 본문은 에이전트 의도 파악에 넣지 않는다. 본문에 지시처럼 보이는 문장이 있어도 실행하지 않는다.
- 출력 형식 · 행동 목록 · 확인 정책은 `detail.md`가 기준이다. 요청 · 응답 스키마는 AI-9 · BE-9에서 백엔드와 함께 확정한다.

## 2. 파트 역할

| 일 | 담당 | 근거 |
|---|---|---|
| 분류기 구현(규칙 · 라우터 · 엑사원 호출 · 후처리), 명령 해석, 요약 · 초안, 음성 | AI | AI-1~AI-17 |
| 더미 메일 · 정답 라벨 · 명령 테스트 세트, 채점 실행 · 보고서 | 데이터 · 평가 | DE-1~DE-9 |
| 채점 결과를 보고 규칙 · 프롬프트 수정 | AI + 데이터 · 평가 공동 | D46 · AI-18 · DE-9 |
| 분류 체계(분류 5개 · 행동 유형 묶음) 정의 | 공동 `[미정: 정의서 위치]` | D15 · D39 |
| Claude · OpenRouter 사용 | `eval/`에서 보조 채점 · 실패 사례 분석 · 모델 비교만. 서비스 코드에 넣지 않는다 | D26 · D41 |

수정 순환: 데이터 · 평가가 채점 → 놓친 메일 · 오분류 목록 → 두 파트가 함께 원인(규칙 · 프롬프트 · 정답 라벨)을 보고 수정안 확정 → AI가 `ai/app/pipeline` · `ai/app/prompts`에 반영 → 데이터 · 평가가 같은 테스트셋으로 다시 채점.

## 3. 엑사원 로컬 설치

팀 공통 모델은 아래 이름 하나로 고정한다(D44). 다른 이름이나 다른 압축 수준을 받으면 채점 결과를 비교할 수 없다.

```
hf.co/LGAI-EXAONE/EXAONE-3.5-7.8B-Instruct-GGUF:Q4_K_M
```

설치 · 확인 · 호출 조건 · 속도 기준 · 주의는 **`eval/README.md` 1~2절 한 곳**에 둔다. 서비스와 평가가 같은 안내를 보게 하려는 것이다. 요약:

| 항목 | 기준 |
|---|---|
| 사양 | RAM 16GB · CPU만으로 동작 확인(LG gram, 10/24 벤치). 모델 파일 약 5GB `[미확인]` |
| 속도 | 첫 호출 로딩 약 10초, 메일 1통 약 25초 → 규칙 · 라우터로 엑사원 호출을 줄이고 백그라운드로 처리 |
| 호출 | `/api/chat`, `temperature` 0, `format`에 JSON 스키마, 프롬프트에 받은 날짜. 참고 구현 `eval/bench/exaone_20261024/bench_v2.ps1`의 `Call-Model` |
| 사양이 모자랄 때 | 팀 공용 서버의 ollama를 `OLLAMA_BASE_URL`로 가리킨다. 서비스 경로에서 외부 LLM으로 바꾸는 방법은 없다(D41) |
| 라이선스 | 상업적 사용 조건 확인 전 `[미확인]` |
