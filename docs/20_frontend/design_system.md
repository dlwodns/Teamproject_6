## 1. 색 — 60 · 35 · 5

LG CNS 사이트도 무채색이 압도적이고(토큰 참조 수: 구분선 59 · 본문 글자 55 · 보조 글자 49 … 브랜드 빨강 11) 빨강은 포인트로만 쓴다. 그래서 **60%는 무채색 면, 5%가 LG 빨강**이다. 빨강을 넓게 깔면 촘촘한 업무 목록에서 눈이 피로하고 '기한 지남(위험)'과 구분되지 않는다.

| 비율 | 이름 · 토큰 | HEX | 어디에 | 흰 바탕 대비 |
|---|---|---|---|---|
| **60%** 바탕 | `--c-surface` | #FFFFFF | 카드 · 패널 · 상단 바 | — |
| | `--c-canvas` | #F7F8F9 | 페이지 바탕 · 카드 안 작은 면 | — |
| **35%** 보조 1 | `--c-ink` | #121212 | 본문 글자 · 체크된 상자 · 포커스 링 · 토스트 바탕 · 긴급 라벨 | 18.73:1 |
| 보조 2 | `--c-gray` (LG GRAY) | #6B6B6B | 보조 글자 · 아이콘 · 로고 글자 | 5.33:1 |
| 보조 3 | `--c-line` | #E5E5E5 | 구분선 · 카드 테두리(장식) | 1.26:1 |
| 보조 4 | `--c-fill` | #F0F1F3 | 선택 행 · hover · 칩 · 분할 버튼 바탕 | 1.13:1 |
| **5%** 포인트 | `--c-point` (LG Heritage Red) | #A50034 | **주 버튼 · ✦ 에이전트 버튼 · 선택 메뉴 밑줄 · 로고만** | 7.93:1 (흰 글자 올림) |
| | `--c-point-press` | #610024 | 주 버튼 누름 | — |

보조 글자 크기가 작을 때는 `--c-sub` #565656(7.34:1), 입력칸 테두리는 `--c-input` #8E8E8E(3.28:1, UI 3:1 충족 · **글자 금지**)를 쓴다. 로고 SVG가 쓰는 값은 얼굴 #A50034 · 글자 #6B6B6B다. LG CNS 사이트 주 버튼은 #9B002E인데 #A50034와 대비 1.09:1로 사실상 같은 색이라 로고 값 하나로 통일한다.

**포인트 규칙**
- 포인트 빨강은 "채운 버튼"과 "선택 표시선"에만 쓴다. 글자 · 배지 · 아이콘 · 차트에 쓰지 않는다.
- 선택은 색만으로 나타내지 않는다: 메뉴는 굵은 글씨 + 밑줄, 분할 버튼은 흰 바탕 + 그림자, 메일함은 굵은 글씨 + 왼쪽 선.
- 체크 상자 · 진행 막대 · 단계 점은 빨강이 아니라 `--c-ink` · 완료색이다.

### 기한 라벨 (UX-D10)

| 상태 | 라벨 예 | 바탕 | 글자 | 글자 대비 |
|---|---|---|---|---|
| 기한 지남 · ASAP | `D+2` · `ASAP` | **검정** #121212 | 흰색 | 18.73:1 |
| 오늘 마감 | `오늘 18:00` | **파랑** #DDF3FB | #003374 | 11:1 이상 |
| 기한 남음 | `내일 12:00` · `11/10(화)` · 메일 목록 `완료` | **초록** #D4F5C7 | #004121 | 9.9:1 |
| 기한 없음 · 응답 대기 경과일 · 분류 | `기한 없음` · `4일` | 회색 #F0F1F3 | #565656 | 6.4:1 |

- 가장 급한 것이 가장 진한 색(검정)이다. 빨강은 포인트 전용이라 라벨에 쓰지 않는다 → 포인트 빨강과 '위험'이 섞일 일이 없다.
- 라벨 글자는 짧게: ⚠ · '기한 지남' · '째' 같은 말을 붙이지 않는다. 숫자 · 시각은 Outfit.
- 검정 라벨은 긴급 칸 제목 앞 점과 같은 색이라 "긴급 = 검정"으로 한 번에 읽힌다.

### 그 밖의 상태색

| 상태 | 글자 | 옅은 바탕 | 쓰는 곳 |
|---|---|---|---|
| 정보 | #003374 | #DDF3FB | 확인 사유 칩 · 새 업무 점(#0755B9) · 분류 대기 안내 |
| 완료 | #004121 | #D4F5C7 | 진행 막대(#209359) · 보냄 ✓ |

- 위험 빨강과 포인트 빨강은 대비 1.11:1로 색으로는 구분되지 않는다. 그래서 위험색은 거의 쓰지 않고, 쓸 때는 옅은 바탕 + 글자로만 쓴다.
- 값은 LG CNS 사이트 팔레트에서 가져왔다. #FFE4E0 · #DDF3FB는 사이트 값(#FFD0CB · #C4ECFA)을 큰 면에서 덜 튀게 밝힌 파생값이다 `[제안]`.

## 2. 서체

| 역할 | 서체 | 굵기 · 크기 | 근거 |
|---|---|---|---|
| 국문 제목 | **Pretendard** | 700 · 20 / 16 / 14px | LG CNS 사이트 `--typo-pc-family-head` |
| 국문 본문 | **Pretendard** | 400 본문 · 500 강조 · 600 버튼 · 14px | LG CNS 사이트 `--typo-pc-family-body` |
| 영문 본문 | **Pretendard**(Inter 기반 라틴 글자 포함) | 국문과 같음 | 한 문장 안 한영 섞임에서 글자 높이가 맞는다 |
| 영문 표시 · 숫자 | **Outfit** 600 | 브랜드 'CNE' · 큰 숫자(업무 수 40px) · 시각 · 경과일 | LG CNS 사이트 메인 배너 `--typo-main-family` |

- 대체 순서: `"Pretendard Variable", Pretendard, -apple-system, BlinkMacSystemFont, "Apple SD Gothic Neo", "Malgun Gothic", "Noto Sans KR", sans-serif`
- 라이선스: Pretendard · Outfit 모두 SIL OFL 1.1 — 빌드에 넣어 배포할 수 있다(FE-1의 `public/licenses/` 고지 방식 유지). Outfit은 라틴 글자만 있어 한글에 쓰지 않는다.
- LG 전용 서체(LG EI Headline · LG EI Text, 예전 LG스마트체)는 "LG전자 전용 서체"이고 외부 사용 조건을 확인하지 못했다 `[미확인]` → 쓰지 않는다.
- 숫자가 세로로 줄 서는 곳(건수 · 시각)은 `font-variant-numeric: tabular-nums`.
- 크기 단계: 12 · 13 · 14 · 16 · 20 · 28 · 40px. 줄 간격 본문 1.5, 메일 본문 1.7.

## 4. 움직임 · 버튼 모핑

| 토큰 | 값 | 쓰는 곳 |
|---|---|---|
| `--d-fast` | 100ms | 누름 · hover 바탕 |
| `--d-short` | 150ms | 체크 · 내용 바꿈(버튼 안 글자 ↔ 스피너) · 팝오버 |
| `--d-move` | 250ms | 줄 빠짐 · 토스트 등장 |
| `--d-panel` | 300ms | 패널 · 시트 등장(퇴장은 200ms) |
| `--e-std` | cubic-bezier(.2,0,0,1) | 기본(M3 emphasized) |
| `--e-in` | cubic-bezier(.05,.7,.1,1) | 들어올 때(감속) |
| `--e-out` | cubic-bezier(.3,0,.8,.15) | 나갈 때(가속) |

**모핑을 쓰는 곳과 안 쓰는 곳** — 업무 화면이라 '간결하고 눈에 덜 띄는' 쪽(Carbon productive)이 기본이다.

| 상호작용 | 모핑 | 방식 |
|---|---|---|
| 업무 ☐ → ✓ → 줄 빠짐 | O | 체크 150ms → 오른쪽으로 빠지며 흐려짐 250ms → 높이 접힘 200ms(`grid-template-rows: 1fr → 0fr`) |
| [보내기] → 보내는 중 → 보냄 ✓ | O | 같은 자리에서 내용만 바꾼다. 글자는 `visibility`로 숨겨 **버튼 폭을 유지**, 스피너는 위에 겹침. ✓는 0.7초 뒤 시트로 넘어감 |
| ✦ 에이전트 버튼 → 패널 | O | 컨테이너 변형 350ms(`document.startViewTransition`, 미지원이면 미끄러짐) |
| 아래 시트 | O | `<dialog>` + `@starting-style`로 아래에서 올라옴 |
| 필터 · 기간 바꾸기 · 탭 | X | 즉시 바꾼다(숫자가 튀지 않게) |

- 1초 안에 끝나는 일에는 스피너를 띄우지 않는다(300~400ms 지연 뒤 표시).
- 로딩 중 버튼은 `disabled`가 아니라 `aria-disabled="true"`(포커스 유지), 상태 문구는 숨긴 `aria-live="polite"` 영역에 "보내는 중" · "보냈어요".
- `prefers-reduced-motion: reduce`면 이동 · 변형 · 깜빡임을 끄고 상태 바뀜만 즉시 보인다.
- `interpolate-size`(height: auto 애니메이션)는 Chrome 계열만 지원 → 쓰지 않는다.

## 5. 문구

| 원칙 | 예 |
|---|---|
| 진행 중은 진행형, 끝나면 과거형 | "대상 업무를 찾는 중…" → "3건을 완료로 바꿨어요" |
| 버튼은 일어날 일을 동사로 | [3건 완료 처리] [메일 보내기] [다시 시도]. 확인 시트만 사용자가 정한 "예 / 아니오" |
| 필요 없는 말은 덜어낸다 | 화면 제목 · 설명 줄 · 경고 줄을 두지 않는다. 빈 상태는 "없음", 오류는 "불러오지 못함 [다시 시도]", 시트에는 제목 · 체크박스 · 버튼만 |
| 결과는 한 줄로 | "3건을 완료로 바꿨어요" · "리마인드 유지" · "중지했어요. 바뀐 것은 없어요" |
| 사용자 말로, 명사로 짧게 | lane=할 일 → '업무', lane=확인 · 참고 → '확인사항', excluded → '제외', snoozed → '나중에', 답장 대기 → '응답 대기' |
| 존댓말은 '~해요' 체로 통일 | 버튼 · 메뉴는 명사형('완료', '나중에', '메일 화면에서 열기') |
| 날짜 | 11/6(금) · 오늘 18:00 · 내일 12:00 · D+2. 모든 시각 KST |

화면 문구는 모두 한국어다. 고유명사(CNE · Catch & End · ASAP)만 영문.

## 6. 접근성 체크

- 글자 4.5:1, 상태 표시 · 포커스 링 · 입력칸 테두리 3:1 이상(FE-1 `contrast.test.ts`로 토큰 값 검사 유지).
- 포커스 링: 2px `--c-ink` + 2px 띄움, 모든 버튼 · 줄 · 칩.
- 키보드만으로: Tab으로 업무 줄 체크 · 메일 이동 · 답장 · 보내기 · 시트 예/아니오까지. 메일 화면에서 Ctrl+B(⌘B)로 메일함 열고 닫기(`aria-keyshortcuts`). Esc는 메뉴 → 알림 센터 → 패널 순으로 하나씩 닫는다. 시트 위에서 Esc는 '아니오'.
- 화면 읽기: 토스트 영역 `role="status"`, 에이전트 패널 `role="status"` 한 곳에 단계 문구만. 오류만 `role="alert"`.
- 색만으로 정보를 주지 않는다: 기한 라벨은 글자 자체가 상태를 말한다(D+2 · ASAP · 오늘 · 날짜), 선택은 굵기 · 선, 새 업무 점에는 `aria-label="새 업무"`.
