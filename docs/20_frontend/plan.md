## 5. 다른 파트와의 접점

| 방향 | 상대 파트 | 내용 |
|---|---|---|
| 받는 것 | 백엔드 | 업무 · 메일 · 설정 API 형식 (`backend/app/schemas`) |
| 받는 것 | AI | 에이전트 응답 형식(실행할 기능 · 확인 문구) |
| 주는 것 | AI | 음성 인식 결과 글자 → 에이전트 입력 |
| 받는 것 | 기획 | 와이어프레임 · 결정 필요 5건 결과 |

## 6. 완료 기준 (입력 → 기대 결과)

- `wireframe.md` 12-4 테스트 V-1 ~ V-12를 모두 통과한다.
- 예: 기본 더미(26건 중 11건 완료) 접속 → 원형 42%, 완료 11 · 미완료 15 표시(V-2).

## 7. 위험

- 백엔드 API가 늦으면 화면이 멈춘다 → `src/api/`에 모의 데이터로 먼저 개발하고 형식만 맞춘다.
- Web Speech API는 브라우저마다 지원이 다르다 `[불확실]` → 버튼 숨김 · 글 입력으로 대체.
