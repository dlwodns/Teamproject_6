> 상태: 제안 · 작성: 문규남 · 결정: [파트 담당 확정 후] · 리뷰: [미정] · 갱신: 2026-11-07 (홍태겸: v3.1 범위 반영, BE-10~BE-17 추가 / 11-07 #6 리뷰 반영: BE-1 · BE-2 상태, D47 · D48 · 무응답 범위)
> 목표일은 과정 일정 기준 제안이다(10/31 MVP 1차 · 11/7 에이전트 · 자동화 결합 E2E · 11/14 실배포 · 11/21 고도화 · 11/28 IR Day).

## 1. 목표

FastAPI(D38) + APScheduler + SQLite로 메일을 가져와 업무 단위로 저장하고, 대시보드 · 메일 · 설정 · 에이전트가 쓰는 API를 제공한다. 업무 상태를 사용자가 완료할 때까지 추적하고(D36 · D48) 리마인더를 보낸다(D35). 행동형 에이전트의 행동 레지스트리 · 확인 판정 · 실행을 맡는다(D37). 메일 연동 시 개인정보 처리(동의 · 암호화 · 최소 저장)를 맡는다.

## 2. 범위

| 이번 단계 (11/14 배포까지) | 이후 |
|---|---|
| dummy 연동, 업무 · 메일 · 설정 API, 상태 변경 · 되돌리기 · 일괄 완료(`action_log`), 행동 레지스트리 · preview/execute, 리마인더 스케줄러, 무응답 계산, 회신 감지 → 완료 확인, Outlook OAuth 연동(보낸편지함 포함), 개인정보 처리 | 캘린더 API(P1), 템플릿 전송 · MCP 서버(P2), IMAP 등 다른 메일 서비스, 자동 동기화 주기 조정 |

- P1 · P2는 P0 완료 전 착수하지 않는다(PL detail 12절). MCP 서버는 일정이 밀리면 뺀다. 지금은 레지스트리에 MCP 노출 이름 칸만 둔다(`detail.md` 5절).

## 5. 다른 파트와의 접점

| 방향 | 상대 파트 | 내용 |
|---|---|---|
| 주는 것 | 프론트엔드 | API · 응답 형식 (구조도 8절), 결과 카드 · preview · 되돌리기 `action_id` |
| 받는 것 | 프론트엔드 | 에이전트 명령 + 선택한 메일 id(`selected_mail_ids`, 지시어 해석용) |
| 받는 것 | AI | `POST /classify` 분류 결과(분류 · 할 일 · 기한 · 우선순위) |
| 받는 것 | AI | `POST /agent/plan` 행동 · 대상 · 인자 → 백엔드가 검증 · 확인 판정 · 실행 |
| 주는 것 | AI | 개인정보 가린 메일, 행동 레지스트리 목록(`{id, name, description}`, D47) |
| 맞추는 것 | AI | 행동 목록(T01~T14) 내용은 AI detail 2절, 구현 구조는 이 파트 `detail.md` |
| 받는 것 | 데이터 · 평가 | 보낸편지함 · 회신 스레드 포함 더미 메일(무응답 테스트), 리마인더 시간 시뮬레이션 테스트 |
| 맞추는 것 | 인프라 | CI backend 단계(`backend/pyproject.toml` + pytest), 스케줄러 단일 프로세스 운영 |

## 6. 완료 기준 (입력 → 기대 결과)

- 구조도 v3.1 12절 테스트 19건 중 백엔드 항목을 통과한다.
- CI backend 단계가 건너뛰지 않고 통과한다(INF-9).
- 예: 완료 처리한 업무가 있는 상태에서 재동기화 → 상태 유지, 중복 저장 없음.
- 예: "공지 메일 다 처리했어"(대상 3건) → preview 반환 · 상태 변경 없음 → execute 후 3건 완료 · `action_log` 1건.

## 7. 위험

- 계정 연결 방식 미정: 서버 대리 로그인은 Outlook.com에서 동작하지 않는다(BE-T1). OAuth 앱 등록의 외부 로그인 제한 `[불확실]` → 시연은 팀 테스트 계정.
- 사내 메일 연동 불가: 실제 성능은 더미 메일로만 확인한다.
- 일정: BE-1 · BE-2 목표일(10/31)이 지났고 11/7까지 P0 작업이 많다 → BE-1 → BE-2 → BE-4 · BE-11 순으로 먼저 하고, P1 · P2는 P0 완료 전 착수하지 않는다.
- 스케줄러 중복 · 유실: 단일 프로세스 · 유일 제약 · 재시작 복구(PL detail 15절 R3).
