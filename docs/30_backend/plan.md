# 백엔드 구현계획

> 상태: 제안 · 작성: 문규남 · 결정: [파트 담당 확정 후] · 리뷰: [미정] · 갱신: 2026-10-30
> 목표일은 과정 일정 기준 제안이다(10/31 MVP 1차 · 11/7 에이전트 · 자동화 결합 E2E · 11/14 실배포 · 11/21 고도화 · 11/28 IR Day).

## 1. 목표

FastAPI(Spring Boot 논의 중) + SQLite로 메일을 가져와 업무 단위로 저장하고, 대시보드 · 메일 · 설정 · 에이전트가 쓰는 API를 제공한다. 메일 연동 시 개인정보 처리(동의 · 암호화 · 최소 저장)를 맡는다.

## 6. 완료 기준 (입력 → 기대 결과)

- architecture 5절 테스트 10건(구조도 v3에서 갱신)을 통과한다.
- 예: 완료 처리한 업무가 있는 상태에서 재동기화 → 상태 유지, 중복 저장 없음.

## 7. 위험

- 계정 연결 방식 미정: 서버 대리 로그인은 Outlook.com에서 동작하지 않는다(BE-T1). OAuth 앱 등록의 외부 로그인 제한 `[불확실]` → 시연은 팀 테스트 계정.
- 사내 메일 연동 불가: 실제 성능은 더미 메일로만 확인한다.
